# P3 前 IMU 补丁

日期：2026-10-03。软件补丁完成；已随P3固件上板验证启动标定、温度和发布延迟诊断，末段运动专项硬件复测仍待补。详见p3-attitude.md。

## 标定末段运动

累计3秒统计之外，增加两段相邻50ms在线统计，合并检查最近约50–100ms。沿用现有均值/方差门限，不缓存原始样本，不分配内存。任何运动/无效/时间错误均清空两路长短窗口，放稳后重新收集连续3秒。

旧版把“前2.8秒静止、末0.2秒绕重力轴以0.1rad/s转动”接受为零偏0.006698rad/s；新版Debug/Release均拒绝。跨短区间边界、末段加计方向改变与连续序号下停止运动的恢复有回归测试。门限以下或极短运动仍可能漏检，标定必须固定板卡。

## P3 读取接口

采样端仅发布独立时间戳和序号，快照的accel_is_new保持false。每个姿态消费者持有自己的core::ImuCursor，通过imu::take_sample(cursor,sample)读取：两种标定都成功后才提供输入；每个有效新陀螺最多提供一次；新加计由消费者自己的序号/时间判断。晚于本帧陀螺的加计暂时无效，之后可在下一陀螺帧消费；无效加计不推进加计游标。重复、倒退、未可用和过期的陀螺不修改输出。

诊断snapshot()不会消耗姿态游标。序号uint32回绕可继续，首次序号0有效。游标允许序号跳跃，以便P3根据两帧陀螺measured_us及checked_delta显式处理丢帧/过大时间间隔；它不把丢样静默钳制成正常dt。

## 采样与诊断

加载加计参数、接受陀螺参数时完整验证一次；每个样本只进行修正算术与有限值检查。安装变换移到中断关闭区外，完整标定信息仅在初始化/接受时复制。短窗口只在启动标定阶段计算，成功后停止学习。

同一采样线程约1Hz读取温度，不新增线程/互斥锁。标定参考温度固定，当前温度和温差单独发布。没有温控或温漂补偿。新USB字段见imu-calibration.md。

发布计时在共享状态发布区临近结束处取时间，包含读取、标定/修正、安装变换和主要共享状态写入；不包含取时间后的少量元数据/统计赋值、中断恢复、日志入队或USB传输。达到本路周期时修正样本无效，并增加publication_late；原始读取valid不因发布迟到改变。P3解算计时以后另外接入。
